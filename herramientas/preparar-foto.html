Preparar foto de item

Arrastra tus fotos (o pégalas con Ctrl+V). Salen listas para subir a la tienda: horizontal 3:2, 640×427, formato WEBP liviano. Todo ocurre en tu computadora; nada se sube a internet.

📷 Arrastra aquí tus fotos o haz clic para elegirlas · también puedes pegar con Ctrl+V
Cómo usarla: 1) Pon tu foto. 2) Si hace falta, arrastra la imagen para centrar el item o usa el control de zoom. “Completo” muestra toda la foto con fondo gris; “Llenar” recorta para llenar el cuadro. 3) Descarga. 4) En la tienda: modo administrador → ✎ Editar el item → Subir foto.
